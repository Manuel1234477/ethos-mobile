# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for the Ethos-Protocol mobile app. ADRs capture the rationale behind significant architectural decisions so that future contributors understand not just what was decided, but why.

## Format

Each ADR follows the template in [adr-template.md](adr-template.md). ADRs are numbered sequentially and are immutable once accepted — a new ADR supersedes an old one rather than editing it in place.
